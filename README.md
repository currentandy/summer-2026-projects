# Research Projects

Independent research projects in hardware/firmware design and computational neuroscience.

## Projects

### [Power Integrity & Noise Analysis Tester](./power-integrity-noise-tester)
A 4-layer PCB power integrity measurement system for sub-mV ripple characterization, combining custom hardware, STM32 firmware, and a Python analysis pipeline exploring topological data analysis (TDA) for noise characterization.

**Tech:** PCB design, STM32, Embedded C, Python, ADC/UART, TDA

### [Topological Analysis of Neural Circuit Constraints](./topological-neural-circuit-analysis)
A graph-theoretic framework evaluating whether analog neuromorphic circuit abstractions preserve biological neural connectivity structure, using retinal ganglion cell network simulations and SPICE-equivalent circuit mappings.

**Tech:** Brian2, SPICE, Python, Graph Theory, Topological Data Analysis
